# QAgent 0.1.0

Primera versión instalable de QAgent: genera y valida pruebas unitarias (pytest) para código Python 3.10+ con tres agentes de IA (Planner, Generator y Reviewer), ejecutándolas en un entorno Docker aislado.

## Cómo instalar

- **Windows (recomendado):** descarga `QAgent-0.1.0-instalador.exe` de esta página y ejecútalo. No necesita Python ni permisos de administrador. Si aparece «Windows protegió tu PC»: *Más información → Ejecutar de todas formas* (el instalador aún no está firmado).
- **Con pip:** `pip install qagent-pytest` y luego `qagent`.

Antes de la primera corrida: Docker Desktop abierto y las claves de API en la pantalla **Configuración** (o `QAGENT_FAKE_LLM=1` en `~/.qagent/.env` para probar con la IA simulada). La primera corrida prepara el entorno de Docker sola: necesita internet y tarda unos minutos.

## Qué incluye

- Pantallas de inicio, vista previa, configuración de pruebas, monitor en vivo, ejecución, informe exportable e historial de corridas.
- Pruebas unitarias de funciones y de endpoints FastAPI.
- Detección de aserciones relajadas para forzar que una prueba pase (*Assertion Laundering*), hasta 3 intentos de corrección por prueba.
- Métricas por prueba: si pasó, cobertura de líneas y ramas, intentos, tokens por agente y Mutation Score en funciones críticas.
- Configuración de las API de cada agente dentro del programa.

## Novedades de distribución (TA-06)

- Instalador para Windows y paquete en PyPI (`qagent-pytest`).
- Los datos del usuario (claves, configuración, proyectos recientes) se guardan en `~/.qagent/`, nunca junto al programa; desinstalar no los borra.
- La versión que muestran la interfaz y los informes es siempre la real (antes decían «v2.4»).

## Limitaciones conocidas

- Solo Windows 10/11 de 64 bits para el instalador.
- El instalador no está firmado digitalmente: Windows lo advierte la primera vez.
- Fuera de alcance: integración contra servicios reales, extremo a extremo, carga y estrés.
