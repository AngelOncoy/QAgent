# QAgent 0.2.0

Segunda versión de QAgent: interfaz rediseñada por completo, configuración de pruebas por opciones (con perfil Humo y Profundo), mutation testing acotado a lo crítico, pruebas repetibles con detección de regresiones, informes más completos y un sandbox más robusto.

## Cómo instalar

- **Windows (recomendado):** descarga `QAgent-0.2.0-instalador.exe` de esta página y ejecútalo. No necesita Python ni permisos de administrador. Si aparece «Windows protegió tu PC»: *Más información → Ejecutar de todas formas* (el instalador aún no está firmado).
- **Con pip:** `pip install --upgrade qagent-pytest` y luego `qagent`.

Si vienes de la 0.1.0, tus claves, configuración y proyectos recientes en `~/.qagent/` se conservan. Antes de la primera corrida: Docker Desktop abierto y las claves de API en la pantalla **Configuración**.

## Novedades

### Interfaz rediseñada

- Nueva identidad visual, pantalla de Inicio y barra lateral retráctil.
- Pantallas nuevas para abrir y clonar proyectos.
- Explorar, Preparar, Configuración, En curso, Resultados, Exportar e Historial migrados al nuevo diseño; se retiró la paleta antigua y el tema claro.
- Interfaces responsivas, botón para volver a la pantalla principal desde cualquier módulo y, en la ejecución en vivo, doble scroll y cuadro de búsqueda.

### Vista previa y selección de objetivos

- Nueva vista previa con indicadores de calidad y plegado por archivo.
- Selector de funciones y endpoints a probar.
- Aviso claro cuando el proyecto abierto o clonado no es Python.
- Mejor selección de objetivos y elección de la carpeta de clonación.

### Configuración de pruebas

- La configuración de pruebas pasa a ser un conjunto de opciones en lugar de planes fijos.
- **Perfil Humo:** un caso normal por objetivo, para una revisión rápida.
- **Perfil Profundo:** además muta el manejador de los endpoints prioritarios (caja blanca).
- Cada caso de prueba indica su categoría: normal, límite o error.
- Las marcas de **Profundizar** (funciones críticas) llegan a la corrida y al spec.

### Mutation testing y regresiones

- Mutation testing acotado a las funciones marcadas como críticas, nunca al repositorio completo.
- Al repetir pruebas guardadas se vuelve a aplicar la mutación.
- Las pruebas repetidas se marcan en la interfaz, junto con el motivo de una regresión.

### Informes

- Informe de detalles por prueba.
- Contenido más completo en los reportes descargados.

### Proveedores de IA

- Nuevo proveedor **DeepSeek**, como alternativa económica.
- Límites de verificación editables desde la pantalla Configuración.

### Estabilidad

- Límites del sandbox revisados y corridas más robustas cuando la IA responde lento.
- Limpieza automática de contenedores huérfanos e imágenes de dependencias sin uso en Docker.
- Los proyectos recientes se guardan de forma segura, incluidos los repositorios clonados, y los módulos se habilitan al reabrir un proyecto que ya tiene pruebas.
- Corregida la detección de funciones duplicadas al reutilizar un spec.
- Correcciones generales de estabilidad y de la Vista previa.

## Limitaciones conocidas

- Solo Windows 10/11 de 64 bits para el instalador.
- El instalador no está firmado digitalmente: Windows lo advierte la primera vez.
- Fuera de alcance: integración contra servicios reales, extremo a extremo, carga y estrés.
